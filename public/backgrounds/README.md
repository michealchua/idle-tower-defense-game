Drop chapter background images here with these exact filenames:

- `forest.png` — chapter 1, 5, 9, ...
- `desert.png` — chapter 2, 6, 10, ...
- `deep-sea.png` — chapter 3, 7, 11, ...
- `volcano.png` — chapter 4, 8, 12, ...

Recommended size: 400x300 (or same 4:3 ratio) — it's stretched to fill the canvas.
Until a file exists, that biome falls back to a solid tint color instead of a broken image.

Mapping lives in `src/data/biomeConfig.ts` (`getBiomeForChapter`) if you want more biomes or a different cycle order.
